Observação: O F-Droid exige privilégios de root para instalar a Privileged Extension
como um “priv-app” do sistema.

A https://f-droid.org/packages/org.fdroid.fdroid pode utilizar privilégios ou permissões do sistema
para instalar, atualizar e remover aplicativos por conta própria. A única maneira de
obter esses privilégios é tornar-se um aplicativo do sistema.

É aí que entra a Extensão Privilegiada — por ser um aplicativo separado
e muito menor, ela pode ser instalada como um aplicativo do sistema e se comunicar
com o aplicativo principal por meio do AIDL IPC.

Isso traz várias vantagens:

* Menor uso de espaço em disco na partição do sistema
* As atualizações do sistema não removem o F-Droid
* O processo de instalação no sistema via root é mais seguro

Em vez desta versão, a maioria dos usuários vai preferir instalar o
arquivo ZIP de atualização “Over-The-Air” (OTA), chamado
https://f-droid.org/packages/org.fdroid.fdroid.privileged.ota.  Ele serve para atualizar
a Privileged Extension quando ela tiver sido instalada usando o ZIP OTA.
